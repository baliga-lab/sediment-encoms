# Metagenomics of Subsurface Denitrifying Enrichment Communities

This repository contains Jupyter notebooks and scripts written for the analysis of metagenomes produced from microbial enrichments derived from subsurface vadose zone sediment.
These notebooks contain analyses and figures related to the manuscript *Enrichments along gradients resolve eco-evolutionary forces on subsurface microbiomes* that is not yet published, so these notebooks are likely to be updated in response to reviews.

The underlying data are metagenomes that were sequenced from laboratory enrichments under various carbon, nitrate, and pH conditions. 
The metagenomes were sequenced with Nanopore MinION and PromethION sequencers, basecalling was done with Dorado, QC done with BBDuk, assembly done with Flye, and mapping done with BBMap. 
The results were aggregated using Anvi'o for annotation and various analyses. 
Data from Anvi'o is exported and analyzed in the contained Jupyter notebooks for statistical analysis and visualization.
The notebooks are split as they are sectioned in the manuscript.
